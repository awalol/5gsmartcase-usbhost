## 使用方法
 - 需要一个一分二转换器和一个 RTL8153b 网卡（就是f50转网口套件，网卡试过 AX87119b 用不了）

1. 将仓库的 route_test.sh 替换掉你系统内的 /etc/route_test.sh
2. 将内核模块上传到 /home/root
3. 重启进入 U2S 刷入修改后的 uboot.bin 和 boot.bin

## 存在的问题以及猜想，希望其他人进行探索
- USB3 内口需要等待系统启动以后再插入网卡才能识别，如果通讯壳发生了重启需要自己手动插拔（外口 2.0 可以正常重置）
> 猜想：将内外口合并不知道能不能解决这个问题

- 如果能够实现内口持续供电，那就可以免掉一分二转换器，现在内口的供电是一个周期变换的过程
